Welcome to the Concert Hall Setup Wizard

This wizard sets up Node-RED on your computer and starts Tune the Concert Hall, a small game where you fix the digital twin of a concert hall.

Which computer are you using?

Pick the computer you will use for the game. The commands and keys in the next steps change to match it. You can come back and change it any time.

Tested with Node.js 22 and 26 · Node-RED 5.0.9 · Dashboard 2 (@flowfuse/node-red-dashboard).

Room model based on Cairoli, M. & Tagliabue, L. C. (2023). Digital Twin for Acoustics and Stage Craft Facility Management in a Multipurpose Hall. Acoustics 5(4), 909–927. https://doi.org/10.3390/acoustics5040053. Absorption values are assumed for teaching. Sensor data is simulated.

Look: 98.css (MIT, Jordan Scales).

Press ⌘ + Space, type Terminal, press Enter.

Press the ⊞ Win key, type cmd, open Command Prompt. (Not PowerShell.)

Paste this into the window and press Enter:

node -v
Look at the first number. What do you see?
Good. Next skips A2 and goes to A3.
Next takes you to A2 to install Node.js.

zsh: command not found: node means Node.js is not installed. Choose the second answer.

'node' is not recognized as an internal or external command means Node.js is not installed. Choose the second answer.

Paste does not work? Type it by hand: node -v (with a space before -v).

  1. Open nodejs.org and download the LTS version.
  2. Open the downloaded file (.pkg.msi) and click ContinueNext until it is finished.
  3. Close the TerminalCommand Prompt window and open a new one.
Next takes you back to A1 to check again.

The installer asks for your Mac password: that is normal.

The installer shows a box "Tools for Native Modules": leave it unticked and click Next.

A1 still shows the old number? You did not open a new window. Close it and open a new one.

In the TerminalCommand Prompt, paste this and press Enter:

npx node-red@5.0.9

The first time it asks Ok to proceed? (y). Type y and press Enter. Wait 1 to 2 minutes.

Do not close this window. Node-RED stops when you close it. You can minimise it.
What do you see now?
Wait a little more. Yellow [warn] lines are normal, ignore them.
EADDRINUSE: Node-RED is already running in another window. Use that one and choose the first answer.
npx: command not found: Node.js is missing. Go back to A1.
A Windows Firewall box: click Allow.
 Still stuck? Raise your hand.

Yellow lines like [warn] about "credentials" or "projects" are normal.

EADDRINUSE means port 1880 is already used: Node-RED is already running in another window. Use that one.

A Windows Firewall box may appear: click Allow.

Closed the window by mistake? Open a new one and run npx node-red@5.0.9 again.

Open your browser and go to:

localhost:1880

The first time, a box asks Enable Update Notifications. Either button is fine.

Then a tour Welcome to Node-RED 5.0! starts. You can skip it: click the ×.

This site can't be reached: Node-RED is not running. Go back to A3.

Keep this browser tab open. You need it again in A5 and B1.

  1. In the editor, click the menu ☰ (top right) → Manage palette.
  2. Click the tab Install. It looks grey, but it works.
  3. Search for this, click install, then Install again in the pop-up:
    @flowfuse/node-red-dashboard
  4. When it is finished, click Close.
Take the one that starts with @flowfuse, not the old node-red-dashboard (Dashboard 1, no longer supported).
Look at the left column of the editor. Is there a section called dashboard 2?
Scroll down the left column, it is near the bottom. It looks like this: Still missing? Open Manage palette → tab Nodes and check that @flowfuse/node-red-dashboard is in the list.

The Install tab shows nothing when you search: check your internet connection and try again.

You installed the old node-red-dashboard by mistake: in Manage palette → Nodes, click remove next to it, then do step 3 again.

💾 Download concert-hall-exercise.json

Save it in Downloads or on the Desktop. Do not open or change it.

Nothing was downloaded? Right-click the button → Save link as… → keep the name concert-hall-exercise.json.

Part A is finished. Keep Node-RED running.

The same button is always at the bottom of the list on the left (💾 Game file).

  1. In the editor: menu ☰ → Import.
  2. Click select a file to import → choose concert-hall-exercise.json → Import.
  3. Click the red Deploy button (top right).
Node-RED asks about nodes that already exist? Choose Replace, not Import copy. Two copies make the game look broken.

Closed the TerminalCommand Prompt by mistake? Open a new one, run npx node-red@5.0.9 again and wait for Server now running. Your dashboard (A5) is still installed.

Imported it twice with Import copy? Delete the second tab "Concert Hall · editor" (double-click the tab → Delete), then Deploy.

Open this address in your browser. You see the game page. Start to play!

http://localhost:1880/lab

The page is empty or says "Cannot GET /lab": you did not click Deploy in B1.

Node-RED stopped? Go back to A3.
