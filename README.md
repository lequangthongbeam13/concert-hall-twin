# Tune the Concert Hall

Hands-on for the talk *Data Fusion in Digital Twins* (LAB University of Applied Sciences, 2026).

**Guide:** open the GitHub Pages site of this repository (index.html).

- `concert-hall-exercise.json`: import it into Node-RED 5.0.9 with Dashboard 2, then open http://localhost:1880/lab
- The solution is published after the class.

Room model based on Cairoli & Tagliabue (2023), Acoustics 5(4), 909-927. Sensor data is simulated.
